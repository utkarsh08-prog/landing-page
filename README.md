# BSW Landing Theme

Custom WordPress theme for Business Success Workshop landing page.

## Installation

1. Upload the `bsw-landing-theme` folder to `/wp-content/themes/`
2. Activate the theme in WordPress admin panel (Appearance → Themes)
3. Create a new page and select "BSW Landing Page" template
4. Or use Elementor to edit the page

## Features

- Custom logo support (Appearance → Customize → Site Identity → Logo)
- Elementor compatible
- Full-width landing page template
- Responsive design
- Clean, minimal code

## Logo Management

### Option 1: WordPress Customizer
1. Go to Appearance → Customize → Site Identity
2. Upload your logo under "Logo" section
3. Save changes

### Option 2: Manual replacement
Replace the file in: `bsw-landing-theme/images/vl-landing-logo.png`

## Page Template

Use the "BSW Landing Page" template for full-width landing pages.
